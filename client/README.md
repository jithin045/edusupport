# EduSupport — Campus Helpdesk & Ticketing System

EduSupport is an enterprise-grade, mobile-responsive campus helpdesk and ticketing platform designed to streamline student support workflows, manage department queues (Academics, Finance, Hostel, IT), track Service Level Agreements (SLAs) in real-time, and ensure accountability through immutable audit trails.

🏗️ Architecture, Approach & Assumptions
1. Architecture & Tech Stack
Frontend: Next.js (App Router), React, Tailwind CSS v4, react-icons.

State & Routing: Client-side rendering ('use client') with dynamic route parameters (/tickets/[id]) and role-based client-side route protection.

Component Design: Modular architecture featuring reusable components (Sidebar, Navbar, StatusBadge, SlaBadge, CreateTicketModal) and custom Shadcn-style interactive UI dropdowns.

2. Key Assumptions
Role Separation: Users fall into distinct roles stored in local session metadata (STUDENT, STAFF, MANAGER). Students create and track personal tickets; Staff/Managers oversee global queues, update priorities, and manage workflows.

SLA Timelines: Every ticket is assigned a target due date (dueAt). System dynamically monitors health status relative to real-time clocks.

3. Trade-offs
Client-Side Auth State: Storing user session info in localStorage was chosen for rapid prototype simulation during local testing, paired with API token validation.

🛡️ Validation & Important Edge Cases Handled
Mobile Responsiveness: Tables automatically collapse into touch-friendly cards on small viewports. Includes a responsive slide-out mobile drawer menu with a dark backdrop blur overlay.

SLA Breach Calculations: Automatically flags active tickets whose target completion timestamp has passed (dueAt < current time) while excluding resolved/closed items.

Custom Dropdown Outside-Clicks: Custom Shadcn-style select menus close reliably when clicking outside using useRef and global mouse event listeners.

Unauthorized Access Control: Automatic redirection to login if unauthenticated users or students attempt to access staff routes.
