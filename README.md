# EduSupport — Campus Helpdesk & Support Ticketing System

EduSupport is an enterprise-grade, mobile-responsive campus helpdesk and ticketing platform designed to streamline student support workflows, manage department queues (Academics, Finance, Hostel, IT), track Service Level Agreements (SLAs) in real-time, and ensure accountability through immutable audit trails.

---

## 🏗️ Architecture, Approach & Assumptions

### 1. Architecture & Tech Stack
* **Frontend:** Next.js (App Router), React, Tailwind CSS, Axios, Lucide/React Icons.
* **Backend:** Node.js, Express, TypeScript, JSON Web Tokens (JWT), Bcrypt.
* **Database:** MongoDB Atlas (Cloud NoSQL Database).
* **State & Routing:** Client-side rendering (`'use client'`) with dynamic route parameters (`/tickets/[id]`) and role-based client-side route protection.
* **Component Design:** Modular architecture featuring reusable components (Sidebar, Navbar, StatusBadge, SlaBadge, CreateTicketModal) and custom Shadcn-style interactive UI dropdowns.

### 2. Key Assumptions
* **Role Separation:** Users fall into distinct roles stored in local session metadata (`STUDENT`, `STAFF`, `MANAGER`). Students create and track personal tickets; Staff/Managers oversee global queues, update priorities, and manage workflows.
* **SLA Timelines:** Every ticket is assigned a target due date (`dueAt`) calculated dynamically based on priority levels (Critical: 4h, High: 12h, Medium: 24h, Low: 48h).

### 3. Trade-offs
* **Client-Side Auth State:** Storing user session info in localStorage was chosen for rapid prototype simulation during local testing, paired with secure server-side API token validation (`protect` and `authorize` middleware).

---

## 🛡️ Validation & Important Edge Cases Handled

* **Mobile Responsiveness:** Tables automatically collapse into touch-friendly cards on small viewports. Includes a responsive slide-out mobile drawer menu with a dark backdrop blur overlay.
* **SLA Breach Calculations:** Automatically flags active tickets whose target completion timestamp has passed (`dueAt < current time`) while excluding resolved/closed items.
* **Custom Dropdown Outside-Clicks:** Custom Shadcn-style select menus close reliably when clicking outside using `useRef` and global mouse event listeners.
* **Unauthorized Access Control:** Automatic redirection to login if unauthenticated users or students attempt to access restricted staff routes.
* **Strict TypeScript Type Safety:** Removed risky `any` type casts across controllers and middleware, implementing clean interfaces and robust error handling.

## 🚀 Local Development Setup

### 1. Clone & Install Dependencies
```bash
git clone <your-repository-url>
cd edusupport

# Install Server Dependencies
cd server
npm install

# Install Client Dependencies
cd ../client
npm install
2. Configure Environment Variables
Backend (server/.env):

Code snippet
PORT=5000
MONGO_URI=your_mongodb_atlas_connection_string
JWT_SECRET=your_super_secret_jwt_key
Frontend (client/.env.local):

Code snippet
NEXT_PUBLIC_API_URL=http://localhost:5000/api
3. Run Locally
Seed and run backend:

Bash
cd server
npm run seed
npm run dev
Run frontend:

Bash
cd client
npm run dev
Open http://localhost:3000 in your browser.
